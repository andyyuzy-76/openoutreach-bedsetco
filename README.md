# 全品类客户开发工作台

基于 [OpenOutreach](https://github.com/eracle/OpenOutreach)、[OpenOutFind](https://github.com/eracle/OpenOutFind) 和 [OpenOutSend](https://github.com/eracle/OpenOutSend) 改造，保留 GPLv3 许可证及上游声明。

在本机配置自己的业务和邮箱，免费寻找公开公司网站与邮箱、生成开发信草稿，审核后通过自己配置的 SMTP 服务器发送。品类、品牌、产品介绍、市场、客户类型和模板均可自行填写。

**新安装从空白邮件配置和空白业务开始，不需要维护者的邮件服务器、账号、SSH 密钥或客户历史。** 默认接入为 SMTP，旧部署的专用适配器只用于兼容其已有配置和历史。

## 功能

- 自行配置 SMTP 主机、端口、加密方式、认证账号和密码／授权码。
- 支持 STARTTLS、SSL/TLS、无需认证的中继；账号认证必须使用加密连接。
- 自行设置 From、Reply-To 和显示名称。
- 在“每日自动开发”设置每天自动发信数量、发送间隔、候选数量与合计提交上限；填 0 可暂停自动发送。
- 多业务、多品类，各自保存产品事实、市场、买家类型、搜索词、模板和每日启用状态。
- 免费官网搜索、公开邮箱采集、来源记录、CSV 导入、草稿编辑及逐封审核发送。
- 所有业务共用公司去重、退订和提交台账；可导入此前已联系／退订公司名单。
- 提交前保存邮件原文与 Message-ID；失败或结果不明不自动重试。
- 可选 NewAPI 设置。免费采集不调用 AI、BetterContact 或付费数据服务。

SMTP 接受提交后显示“服务器已接收”。这不证明对方服务器接受、进入收件箱或已读；需结合自己的退信邮箱和服务器日志核查原 Message-ID。

## 安装与启动

需要 Python 3.12 和 uv。在仓库根目录执行：

Windows：

```powershell
uv sync --frozen --python 3.12
.\.venv\Scripts\python.exe .\outreach.py
```

安装后也可双击 `启动工作台.cmd`；`关闭工作台.cmd` 会核对项目进程后关闭它。

Linux：

```sh
uv sync --frozen --python 3.12
.venv/bin/python outreach.py --no-browser
```

默认界面：[http://127.0.0.1:8766/](http://127.0.0.1:8766/)。`--no-browser` 不自动打开浏览器，`--port 8767` 可更换端口。旧入口 `bedsetco.py` 保留兼容。

界面仅监听本机。远程部署可通过 SSH 本地端口转发访问；SMTP 发信本身不需要 PowerShell、SSH 或专用服务器包装器。

## 接入自己的邮箱

在“邮件服务器 · 自行配置”按邮箱服务商或自建服务器的实际设置填写：

| 设置 | 内容 |
| --- | --- |
| SMTP 服务器 | 主机名或 IP，如 `smtp.example.com`，不含网址前缀或端口 |
| 端口及加密 | 按服务器要求选择；STARTTLS 常用 587，SSL/TLS 常用 465 |
| 账号认证 | 需要登录时勾选，填写用户名和密码／授权码 |
| 发件邮箱 | 服务器允许该账号使用的 From 地址 |
| 回复邮箱 | 接收回复／退订的 Reply-To；留空使用 From |
| 显示名称 | 可选；留空采用对应业务的署名姓名或品牌 |

保存后可点击“检查已保存配置的连接（不发信）”。保存、连接检查和启动都不会发送邮件；连接检查只验证连接和认证，不验证外部投递。无认证中继可取消账号认证。

密码不在页面回显。留空保留原密码；改服务器、端口、加密方式或用户名时须重新输入。也可通过启动进程的环境变量 `OUTREACH_SMTP_PASSWORD` 提供密码，程序不会把环境中的密码写入配置文件。

变更邮件配置后，旧草稿须明确点击“按当前邮件配置重建草稿”，核对并重新审核。重建按原业务模板替换主题和正文；已提交邮件的原文、账号和 Message-ID 保留。

## 配置业务并使用

1. 新增或完善业务，填写真实品牌、品类、产品介绍、署名、市场和客户类型。
2. 按需要填写搜索词、公司官网、排除条件和英文／中文／自定义模板。
3. 如果此前已经联系过客户，在“导入已有联系／退订公司名单”逐行导入域名或邮箱。
4. 免费找客户或导入 CSV，生成待审核草稿。
5. 核对官网业务、邮箱用途及正文，审核后逐封发送。

每个品类建议建立独立业务。尺寸、材料、包装、认证、价格、MOQ 和交期等仅使用对应产品已确认的信息。`product.md`、`target.md` 只是历史业务示例，不控制新安装的业务。

CSV 列名：`email,company,name,subject,body`。前两列必填；主题与正文留空时按业务模板生成。空模板见 `examples/customer-template.csv`。详细操作见 [使用说明.md](使用说明.md)。

## 每日采集与自动发送

在“每日自动开发”填写**每天自动发信数量**并保存。例如改为 20，自动任务读取 20，不再固定为 1；合计提交上限和新增候选上限不足 20 时会同步提高。发送间隔也在此处设置。“采集与总量限制”可另行提高候选数量和总提交上限。

默认自动数量 1、总提交上限 3、新增候选上限 5、间隔 240 秒；已有实例继承原总提交上限及间隔。填 0 暂停自动发送，仍允许免费采集及额度内的手动发送。所有业务共用额度，手动提交、失败和结果不明的提交也计数；改配置不清零当天历史。没有足够合格客户时，实际数量可能少于设定值。

保存每日数量不改变 SMTP 账号、草稿正文或审核摘要，也不立即发信。完整业务勾选“加入每日自动开发”后，调度程序先读取当前设置及剩余额度：

```sh
uv run --frozen python daily_settings.py --status
```

按剩余新增额度免费采集：

```sh
uv run --frozen python daily_collect.py
```

此入口在已启用业务中轮流采集，读取保存的新增候选上限，扣除当天已找到的公司，**只建立草稿，不发送**。`--count 1–30` 限制本批数量，省略时取剩余额度（每批最多 30 家）。较大数量可分批执行，不重新获得当天配额；每批保留 10 分钟采集预算、抓取间隔及官网规则。`--profile 业务编号` 可指定业务。可以通过 Windows 任务计划程序或 Linux 定时任务安排执行；新克隆不会安装维护者私有的 Codex 任务。

自动发送的调度程序在运行开始、每批采集前、每次发送前重新读取 `daily_settings.py --status`，仅在 `automatic_remaining`、`submission_remaining` 均大于 0 时继续；采集不得超过 `collection_remaining`。不要把固定数量写入调度脚本。核对候选业务、邮箱用途、产品事实、历史与退订，再逐封调用 `bedsetco.approve(编号, automated=True)` 和 `bedsetco.send(编号, automated=True)`。

发送入口还会在提交前重新读取每日设置，强制检查暂停、自动数量、总提交上限和间隔，并要求业务仍启用且版本一致；邮件账号变更须先重建草稿。全部业务、页面和使用同一数据目录的任务共用提交台账。减少数量或填 0 会阻止后续自动提交，不撤回此前已经提交的邮件。

已有部署的每日任务可以继续保留。仅勾选每日业务或启动网页不会创建任务或自动发信。

## 私有数据与迁移

- `data/` 由程序生成并被 Git 忽略，保存业务、队列、私有设置、台账、邮件原文及记录。
- Windows 的 `mail.dpapi`、`finder.dpapi`、`daily.dpapi` 使用 DPAPI，依赖当前用户和机器；跨机器重新录入设置。
- Linux 的 `mail.private.json`、`finder.private.json`、`daily.private.json` 以 `0600` 权限保存，数据目录为 `0700`；没有额外加密。源码忽略 `*.private.json`。
- 更新源码时保留完整数据。新用户无需恢复维护者数据；迁移自己已使用的实例时须保留自己的去重和提交历史。
- 旧专用适配器仅通过实例的私有配置启用，说明见 [ops/README.md](ops/README.md)。普通 SMTP 用户无需这些脚本和其中的服务器配置。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `outreach.py` | 通用启动入口 |
| `bedsetco.py` | 队列、审核、发送和历史；旧模块名兼容既有调用 |
| `mail_transport.py`、`mail_ui.py` | SMTP 配置、连接检查、单封提交和可选旧适配器 |
| `private_store.py` | 私有设置保存与进程间锁 |
| `business_profiles.py`、`profile_ui.py` | 多业务、模板、版本和每日启用 |
| `free_finder.py`、`finder.py` | 免费官网采集及可选 AI 设置 |
| `daily_collect.py` | 定时采集入口 |
| `daily_settings.py`、`daily_ui.py` | 可编辑每日数量、额度与只读调度查询 |
| `ops/` | 可选历史部署适配器源码 |
| `src/` | 三个上游源码快照及修改 |
| `data/` | 私有运行数据，不上传 Git |
